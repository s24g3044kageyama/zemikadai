# ケーキ通販Webアプリケーション (Pâtisserie Douceur)

JavaとHTML/CSS/JavaScriptで構築された、本格的な洋菓子通販Webアプリケーションです。  
外部ライブラリに依存しないPure Java構成（Java 21標準の組み込みHTTPサーバーおよび仮想スレッド）を採用し、軽量・高速かつ堅牢に動作します。

---

## 🌟 主な特徴と仕様

- **サーバーサイド（Java）主導の設計**:
  - すべてのカート状態管理（追加、削除、数量変更、クリア）、および小計・合計金額の計算は**サーバー側のJava**で処理されます（クライアント側JavaScriptによる代用・偽装防止）。
  - クライアントが無効（JSオフ）の環境でも通常のHTMLフォームPOSTによりカート追加・削除・リダイレクトが機能します。
- **セッション維持機能**:
  - `HttpOnly` Cookie（`CAKE_SESSION_ID`）を用いたサーバーサイドセッション管理により、ページ移動やブラウザの再読み込みを行ってもカート内容が安全に維持されます。
- **エレガントなUI/UX**:
  - パティスリーの世界観を表現した洗練されたデザイン（レスポンシブ対応）。
  - 各ケーキの高品質ベクターイラスト（SVG）を内蔵し、オフラインでも鮮明に表示。
- **仮想スレッド対応**:
  - Java 21 の `Executors.newVirtualThreadPerTaskExecutor()` による高い並行処理性能。

---

## 🎂 実装機能一覧

1. **ケーキの商品一覧表示**:
   - 商品名、価格（税込）、商品説明、カテゴリ、美味しそうなケーキ画像の表示（8種類）。
2. **購入個数の指定**:
   - `＋` / `−` ボタン（ステッパー）および数値入力による直感的な個数指定（1〜99個）。
3. **カートへの追加**:
   - カート追加時のスムーズなトースト通知とヘッダーカートバッジのリアルタイム反映。
4. **カート内商品の一覧表示**:
   - サムネイル画像、商品名、単価、数量、小計金額の一覧テーブル表示。
5. **商品ごとの削除**:
   - カート内の任意の商品を行単位で削除可能。カート全クリア機能も搭載。
6. **小計と合計金額の計算**:
   - 商品ごとの単価×数量の小計、および全商品の合計金額を**Javaサーバー側で計算**して表示。
7. **商品一覧に戻る機能**:
   - カート画面のヘッダーおよび注文サマリー下部に「商品一覧に戻る」リンクを設置。
8. **ページ移動・再読み込み後のカート維持**:
   - サーバーサイドセッションにより、別ページへの移動やリロード後もカート内容を保持。

## 🛠️ ビルド方法

### 環境要件
- Java Development Kit (JDK) 21 以上

### ビルドコマンド
プロジェクトルートにて以下を実行します:

```bash
./build.sh
```

実行すると、`src/` 配下のJavaソースコードがコンパイルされ、ルートディレクトリに実行可能JAR `app.jar` が生成されます。

---

## 🚀 起動方法

### 1. 現在のコンテナ環境で起動する場合

ポート 80（デフォルト）で起動します:

```bash
./run.sh 80
```

ポート番号を省略した場合もデフォルトで `80` 番ポートで待ち受けます:
```bash
./run.sh
```

起動が成功すると以下のようなログが出力されます:
```text
==================================================
 ケーキ通販Webサーバーが起動しました
 待受アドレス: 0.0.0.0:80
 静的ファイル配置: /static
 アクセスURL: http://localhost/
==================================================
```

### 2. Dockerコンテナとしてビルド・実行する場合

```bash
# Dockerイメージのビルド
docker build -t cake-shop-app .

# ポート 80 をマッピングしてコンテナ起動
docker run -d -p 80:80 --name cake-shop cake-shop-app
```

## 💻 操作方法

ホスト側のブラウザから以下のURLにアクセスしてください:

👉 **`http://localhost/`**

### 1. 商品一覧の閲覧とカート追加
- トップ画面にアクセスすると、季節のケーキ一覧（8種類）が表示されます。
- 各カードの数量ステッパー（`−` / `＋`）で購入したい個数を指定します（デフォルト: 1）。
- 「🛒 カートに追加」ボタンをクリックすると、サーバーにリクエストが送信され、カートに商品が追加されます。画面右下にトースト通知が表示され、ヘッダー右上のカートバッジ件数が更新されます。

### 2. カート画面の確認
- ヘッダー右上の「🛒 カート」ボタンをクリックするか、直接 `http://localhost/cart.html` にアクセスします。
- カートに入っている商品の一覧、単価、数量、小計金額、および全体の合計金額が表示されます。
- **数量の変更**: カート画面上で `−` / `＋` をクリックするか数値を直接変更すると、サーバー側で小計と合計金額が即座に再計算されます。
- **商品の削除**: 各行の「🗑️ 削除」ボタンをクリックすると、確認ダイアログののち該当商品がカートから削除されます。
- **再読み込み・ページ遷移テスト**: ブラウザをリロード（F5）したり、商品一覧に戻って再度カートを開いても、カートの内容・合計金額がそのまま保持されていることが確認できます。

### 3. 商品一覧に戻る
- カート画面のヘッダーにある「← 商品一覧に戻る」または注文内容下の「← 商品一覧に戻ってお買い物を続ける」をクリックすると、トップページへ戻りお買い物を継続できます。
